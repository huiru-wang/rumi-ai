# 奶油轻彩风

## 1. Vibe — 整体气质

明快、轻盈、有编辑感。以接近纸张的奶油白为底，用薄荷绿、浅蓝、柔粉、柠黄等糖果色块承载主要信息；深墨灰只作为文字、边框、分隔线和少量错位阴影使用。整体气质介于「轻彩信息图」与「知识分享手账」之间——结构清楚，但不沉重；颜色活泼，但不花哨。

关键词：奶油纸底 / 糖果色块 / 深墨灰线条 / 大号数据 / 轻拼贴 / 信息图

## 2. Color System — 色彩系统

```css
:root {
    --bg-primary: #FAF9F6;
    --bg-secondary: #FFFFFF;
    --text-primary: #2A2926;
    --text-secondary: #6B6760;
    --accent-main: #3A3833;
    --accent-highlight: #A8E6A3;
    --accent-muted: #B8E7F7;
    --surface: #F0F0F0;
    --accent-pink: #F9B1E0;
    --accent-yellow: #FFD66B;
    --accent-cream: #F5F1E8;
}
```

| 变量 | 色值 | 角色 | 使用场景 |
|------|------|------|----------|
| `--bg-primary` | #FAF9F6 | 奶白纸 | 页面主背景、深色文字 |
| `--bg-secondary` | #FFFFFF | 纯白 | 卡片底色、引用框背景 |
| `--text-primary` | #2A2926 | 深墨灰 | 主标题、正文、数字 |
| `--text-secondary` | #6B6760 | 暖灰 | 辅助说明、来源标注、弱化文字 |
| `--accent-main` | #3A3833 | 结构深灰 | 边框、分隔线、轻量错位阴影 |
| `--accent-highlight` | #A8E6A3 | 薄荷绿 | 重点卡片、高亮标签、正向信息 |
| `--accent-muted` | #B8E7F7 | 浅蓝 | 次要卡片、说明标签、引用条 |
| `--surface` | #F0F0F0 | 卡片表面 | 中性信息块、底部解说条 |
| `--accent-pink` | #F9B1E0 | 柔粉 | 强调卡片、结论标签、引人注意的信息 |
| `--accent-yellow` | #FFD66B | 柠黄 | 数据高亮、年限标签、关键数字 |
| `--accent-cream` | #F5F1E8 | 米灰 | 对比卡片中的「旧/传统」侧背景 |

**配色逻辑**：每份 deck 以奶油底 + 糖果色信息块为主角，深墨灰仅提供结构和可读性。绿色用于定义/方案/正向，蓝色用于说明/过程，粉色用于结论/强调，黄色用于数据/关键数字。**禁止把内容卡片、信息框、标题条生成成黑色或近黑色底；糖果色块必须保持糖果色。**

## 3. Typography — 字体系统

| 用途 | 中文字体 | 西文字体 | 字重 |
|------|----------|----------|------|
| 超大标题 / 金句 | Noto Sans SC | Archivo Black | Black / 900 |
| 页面主标题 | Noto Sans SC | Archivo | Bold / 700 |
| 副标题 / 引导段 | Noto Sans SC | Space Grotesk | Medium / 500 |
| 正文 / 说明 | Noto Sans SC | Nunito | Regular / 400 |
| 页眉 / 页脚 / 标签 | Noto Sans SC | Space Grotesk | Medium / 500 |
| 数字 / KPI | Noto Sans SC | Archivo | Bold / 700 |

**导入示例**：

```
https://fonts.loli.net/css2?family=Archivo+Black&family=Archivo:wght@400;500;600;700&family=Space+Grotesk:wght@400;500;600;700&family=Nunito:wght@400;500;600;700&family=Noto+Sans+SC:wght@400;500;700;900&display=swap
```

**排版规则**：
- 页面主标题：几何无衬线 Black，视口宽度 6–10vw，左对齐为主，字间距 -0.02em
- 英文副标题 / 引导小字：Space Grotesk 全大写，12–14px，字间距 +0.12em，颜色取 `--text-secondary`
- 正文：Noto Sans SC / Nunito，15–18px，行高 1.5–1.65
- 数字：Archivo Bold，用于数据页与 KPI，字间距 -0.02em
- 卡片标题：Noto Sans SC Bold，20–28px
- 标签文字：Space Grotesk Medium，全大写或首字母大写，11–13px

**核心原则**：几何无衬线负责「视觉冲击」（标题、数字、标签），人文无衬线负责「可读信息」（正文、说明），所有文字保持高对比，禁止在彩色卡片上使用彩色文字。

## 4. Layout Grammar — 布局语法

### Layout Preference — 轻彩信息图倾向

This style works best as a light pastel infographic system. Prefer compact color modules, small labels, arrows, connectors, grouped annotations, and airy diagrams over oversized solid panels.

Candy-colored blocks should feel like information modules or highlights, not heavy walls. When content is sparse, keep blocks smaller and let whitespace, lines, and relationships carry the composition.

For technical or conceptual content, relationship maps, flows, state branches, and annotated mini-diagrams usually fit this style better than large isolated opinion cards. Cards are still welcome when the content is truly categorical or comparative.

### Cover / 封面页

出现频次：1 页

**结构**：页面可使用细到中等粗细的深墨灰外框。顶部可放置一个轻量栏目标签或主题标签，避免与主体引导标签重复。主体左侧垂直排列：糖果色引导标签 → 超大英文缩写标题 → 糖果色底深墨灰文字主标题 → 副标题/引导段。右侧为 3 个纵向堆叠的糖果色条目卡片，每个卡片包含条目编号与条目标题。底部左侧可放说明文字。

**背景**：`--bg-primary` 纯色，可加极淡的噪点纹理或网格点阵作为装饰层。

**占位符**：`栏目标签`、`引导标签`、`英文大标题`、`中文主标题`、`副标题`、`右侧条目 1 标题`、`右侧条目 2 标题`、`右侧条目 3 标题`、`底部说明`

**文字颜色**：主标题与英文标题用 `--text-primary`，彩色卡片内文字用 `--text-primary`，底部说明用 `--text-secondary`。

---

### Data / 数据大字报页

出现频次：1–2 页

**结构**：顶部为糖果色或白底药丸形引导标签。主体左侧为超大数字/KPI，右侧为中文标题与来源说明。底部可保留细长糖果色进度条或深墨灰分隔线，下方只放主题相关说明。数字占据页面视觉中心，标题与数字形成左右呼应。

**背景**：`--bg-primary` 纯色。

**占位符**：`引导标签`、`核心数字`、`数字单位`、`数据标题`、`数据来源`、`页脚说明`

**文字颜色**：数字与标题用 `--text-primary`，来源与页脚用 `--text-secondary`。

---

### Content / 内容页 — 双栏对比型

出现频次：1 页

**结构**：顶部为糖果色或白底药丸形引导标签。主体为左右 1:1 双栏。左栏为浅色/米灰底卡片，代表「旧/传统/ Before」，内部为标签、标题与要点；右栏为糖果色底卡片（常用薄荷绿或浅蓝），代表「新/方案/ After」，内部为标签、标题与要点。两栏之间可用深墨灰箭头或线性箭头连接。底部解说条可选。

**背景**：`--bg-primary` 纯色。

**占位符**：`引导标签`、`左栏标签`、`左栏标题`、`左栏要点`、`右栏标签`、`右栏标题`、`右栏要点`、`底部解说`

**文字颜色**：两栏内部文字均用 `--text-primary`，左栏可适当降低透明度以形成弱化。

---

### Content / 内容页 — 横向分段条型

出现频次：1 页

**结构**：顶部为糖果色或白底药丸形引导标签。主体为一个横向贯穿的糖果色分段条，每段标注百分比与文字说明。分段条下方为二级标题，再下方为 3–5 个横向排列的药丸标签或方框标签。最下方可放来源标注或主题相关说明。

**背景**：`--bg-primary` 纯色。

**占位符**：`引导标签`、`分段条标题 1`、`分段条占比 1`、`二级标题`、`标签 1`（共 3–5 组）、`来源标注`、`底部解说`

**文字颜色**：分段条内文字用 `--text-primary`，标签文字用 `--text-primary`，来源与解说用 `--text-secondary`。

---

### Content / 内容页 — 三栏卡片型

出现频次：1–2 页

**结构**：顶部为页面主标题（可带副标题）。主体为横向排列的三张等宽彩色卡片，每张卡片左上角为编号，中部为卡片标题，下部为说明要点。卡片之间保持等距间隙。底部可附加解说条。

**背景**：`--bg-primary` 纯色。

**占位符**：`页面主标题`、`页面副标题`、`卡片 1 编号`、`卡片 1 标题`、`卡片 1 说明`、`卡片 2 编号`、`卡片 2 标题`、`卡片 2 说明`、`卡片 3 编号`、`卡片 3 标题`、`卡片 3 说明`、`底部解说`

**文字颜色**：卡片标题用 `--text-primary`，说明文字用 `--text-secondary`，编号用 `--text-primary`。

---

### Content / 内容页 — 双栏信息卡型

出现频次：0–1 页

**结构**：顶部为糖果色或白底药丸形引导标签。主体为左右两个糖果色或白底信息卡片。每个卡片顶部使用同色系浅色标题区、细分隔线或小标签，不使用黑色/近黑色标题条；下方为职责、要求、技术等结构化信息。底部解说条可选。

**背景**：`--bg-primary` 纯色。

**占位符**：`引导标签`、`左卡标题区`、`左卡职责`、`左卡要求`、`左卡技术`、`右卡标题区`、`右卡职责`、`右卡要求`、`右卡技术`、`底部解说`

**文字颜色**：标题区和卡片内文字均用 `--text-primary`，辅助说明用 `--text-secondary`。不得出现黑底黑字或深底深字。

---

### Closing / 结尾页

出现频次：1 页

**结构**：与封面页类似，可由深墨灰细到中等外框包围。中央放置大号结语标题，下方为行动号召或总结说明。底部可保留与主题相关的页脚说明。

**背景**：优先使用 `--bg-primary` 纯色或糖果色块拼贴。除非用户明确要求，不使用深色反色整页。

**占位符**：`结语标题`、`总结说明`、`页脚说明`

**文字颜色**：浅色背景用 `--text-primary`，糖果色背景仍用深墨灰文字。

## 5. Signature Elements — 标志性元素

### 深墨灰结构线

结构线使用 `--accent-main` 深墨灰，主要用于外框、卡片边框、分隔线、箭头和轻量阴影。线条应清晰但不沉重，通常 2–3px 即可；不要使用纯黑大面积填充来制造结构。

### 糖果色信息卡片

信息卡片以糖果色填充（绿/蓝/粉/黄）或白底为主，搭配深墨灰边框和深墨灰文字。禁止把糖果色内容卡片替换成黑色/近黑色底。禁止在深色底上继续使用深色文字。错位阴影可以使用 `--accent-main`，但应轻量，不能变成大块黑色视觉面积。

### 药丸形标签

页面顶部或标题上方使用圆角药丸形标签，内部为引导主题或章节名。标签底色优先使用糖果色或白色，带深墨灰边框。标签文字使用几何无衬线，全大写或首字母大写，字间距略宽。

### 错位阴影

主要卡片和标签可带向右下方偏移的深墨灰实色阴影（不使用模糊阴影），形成轻拼贴层次。阴影偏移量保持克制，通常 3–5px；如果阴影让页面变重，应减小或省略。

### 底部解说条

底部说明条是可选元素，用于承载演讲者备注、补充说明或转述文字。底色优先使用 `--surface`、白色或浅糖果色，文字使用 `--text-secondary`；不要使用黑色/近黑色底条。

### 顶部标签体系

内容页顶部只保留一个主要标签：可以是章节标签、主题标签或轻量页眉三选一，不要同时出现多个相似药丸标签。若使用页眉，左侧可用简短文字标识，右侧可用章节名，但应保持低调，不与主体标题区抢层级。

### 页脚与底部说明

正式生成的 PPT 不要出现「横版 · 16:9」等与内容无关的比例或版式签名。底部只放与本页主题相关的简短说明；内容密集页可以省略底部解说条，以免挤压或遮挡主体内容。

## 6. Visual Assets — 视觉资产

本风格不依赖外部图片资源，所有视觉效果由 CSS 生成。

图标统一使用简洁线性图标库，**禁止使用 emoji**。常用图标方向：公司/来源标识、箭头、数据、标签、流程。

若需要使用来源 logo，应使用简化的首字母或文字标识替代真实品牌 logo，保持风格统一。

## 7. Usage Guidelines — 生成新 PPT 时的使用说明

### 整体原则
1. **奶油底 + 糖果色块是主角**：页面以奶油纸底承托信息，主体卡片优先使用薄荷绿、浅蓝、柔粉、柠黄或白底。
2. **深墨灰只做结构**：深墨灰用于文字、边框、分隔线、箭头和少量错位阴影，不用于大面积内容背景。
3. **糖果色卡片承载信息角色**：绿色=定义/方案/正向，蓝色=说明/来源/过程，粉色=结论/强调/争议，黄色=数据/年限/高亮。
4. **大号数字优先**：数据页让数字成为主角，标题与来源作为配角，避免数字过小或信息过载。
5. **不使用 emoji**：所有图标意义用线性图标或文字标签表达。
6. **卡片保持节奏**：内容页的彩色卡片用于信息分区，而不是默认撑满页面；除非刻意做海报式满版构图，否则保持卡片紧凑、留白明确、节奏轻快。
7. **装饰让位内容**：页眉、章节标签、底部说明都是可选装饰；当页面信息较多时，优先删减这些元素，确保主体内容不重叠、不拥挤。
8. **轻彩信息图优先**：机制、流程、关系类内容优先用箭头、连线、小标签、分组注释或轻量图解表达；卡片适合分类、对比和独立观点。
9. **保持前景/背景对比**：任何深色背景都必须使用浅色文字，任何浅色或糖果色背景都使用深墨灰文字；禁止黑底黑字、深底深字。

### 页面生成规则
- **封面页**：奶白底，深墨灰外框，顶部一个轻量标签，左侧大标题，右侧 3 个纵向糖果色条目卡片。
- **数据大字报页**：奶白底，顶部一个药丸标签，左侧超大数字，右侧标题与来源，底部可放主题相关说明。
- **双栏对比页**：左右 1:1 卡片，左侧米灰（旧），右侧薄荷绿或浅蓝（新），中间深墨灰箭头，底部解说条可选。
- **横向分段条页**：顶部标签，横向彩色分段条，下方二级标题 + 药丸标签阵列，底部来源与解说。
- **三栏卡片页**：顶部主标题，下方 3 张等宽彩色卡片，每张含编号、标题、说明。
- **双栏信息卡页**：顶部标签，左右两张糖果色或白底信息卡，顶部用浅色标题区/小标签/细分隔线，下方结构化信息。
- **结尾页**：奶白底或糖果色块拼贴，中央大号结语标题，底部可放主题相关说明。

### 动效建议
- 封面页：元素从屏幕外 stagger 滑入，营造拼贴展开感。
- 数据页：数字采用计数动画，标题与来源随后淡入。
- 对比页：左右两栏分别滑入，箭头最后出现。
- 分段条页：各分段依次延展填充。
- 三栏卡片页：三张卡片从左到右依次弹出。
- 其他正文页：采用级联淡入 + 轻微上移即可。

### 禁止事项
- 禁止把内容卡片、信息框、标题条做成黑色或近黑色底。
- 禁止黑底黑字、深底深字、低对比文字组合。
- 禁止把糖果色信息块替换成黑色结构块。
- 禁止在糖果色卡片上使用白色或浅色文字。
- 禁止使用 emoji。
- 禁止使用真实摄影图片作为页面背景。
- 禁止使用模糊阴影或玻璃拟态效果。
- 禁止让页面元素紧贴外框，必须保留 3–5% 的内边距。
